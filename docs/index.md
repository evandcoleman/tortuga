features:

    details: A scheduled (or on-demand) email built from what Tautulli says was recently added, enriched with TMDB artwork and ratings, with a "leaving soon" section and optional AI commentary.
  - title: Announcements
    details: One-off or scheduled announcement emails, composed from a reusable template library, with send history.
  - title: Recipients & preferences
    details: Recipients sync from Tautulli's friends list. Each gets unsubscribe, per-list preferences, and resubscribe links — no separate mailing list to manage.
  - title: Plex invites
    details: Send Plex server invites with a branded welcome email, backed by your Plex account token and server ID.
  - title: User portal
    details: An optional public site on its own domain — getting-started info, rules, a report-issue flow, and custom pages — for the people you invite.
  - title: Self-hosted, one image
    details: A single Docker image with an embedded SQLite database. Configure via environment variables and tortuga.yml, or the admin UI.
